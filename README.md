## 1. 프로젝트 개요

### 배경 및 목적

수험생 대부분은 기출문제를 **단순 반복 풀이** 방식으로 학습한다.  
출제 경향에 대한 체계적인 분석 도구가 없어, 중요도가 높은 영역을 인식하지 못하고 학습 시간을 비효율적으로 배분하는 문제가 발생한다.

**ExamTrend Analyzer**는 이 문제를 자동화된 데이터 분석으로 해결한다.

| 항목 | 내용 |
|---|---|
| 프로젝트명 | ExamTrend Analyzer |
| 플랫폼 | Python 기반 데스크탑 애플리케이션 |
| GUI 프레임워크 | PySide6 |
| 개발 언어 | Python 3.11 이상 |
| 핵심 기술 | 텍스트 마이닝, 자연어 처리, 데이터 시각화 |
| 제약 조건 | LLM API 사용 금지 · 완전 오프라인 구동 |

### 핵심 가치

- 📊 **객관적 분석** — 감이 아닌 데이터로 출제 경향 파악
- 🔁 **반복 패턴 탐지** — 코사인 유사도 기반 유사 문항 자동 탐지
- 📁 **다양한 입력** — PDF, CSV, Excel, TXT 다중 파일 병합 분석
- 🚀 **완전 독립 구동** — LLM API 없이 순수 통계·NLP만으로 동작

## 2. 시스템 아키텍처

### 계층 구조 (Layered Architecture)

```
┌─────────────────────────────────────────────────────┐
│               Presentation Layer                    │
│    MainWindow │ DashboardPage │ AnalysisPage        │
│               ReportPage                           │
├─────────────────────────────────────────────────────┤
│                 Service Layer                       │
│         AnalysisService │ ReportService             │
├─────────────────────────────────────────────────────┤
│                 Analysis Layer                      │
│  KeywordAnalyzer │ ChapterClassifier                │
│                  SimilarityAnalyzer                 │
├─────────────────────────────────────────────────────┤
│                   Core Layer                        │
│   FileLoader │ PdfLoader │ Models │ Schema          │
│                    Validation                       │
└─────────────────────────────────────────────────────┘
```

**의존성 규칙**: 상위 계층 → 하위 계층 단방향 의존만 허용  
역방향 의존 금지: `Core → UI`, `Analysis → UI`, `Core → Service`

### 데이터 흐름

```
파일 입력 (PDF/CSV/XLSX/TXT)
    ↓
FileLoader / PdfLoader  →  DataFrame 생성
    ↓
컬럼 자동 매핑  →  실패 시 수동 매핑 다이얼로그
    ↓
데이터 검증  →  ValidationIssue 생성 (error / warning / info)
    ↓
텍스트 전처리  →  Kiwipiepy 형태소 분석 (미설치 시 정규식 폴백)
    ↓
┌─ KeywordAnalyzer     TF-IDF 기반 키워드 빈도 분석
├─ ChapterClassifier   키워드 사전 기반 단원 자동 분류
└─ SimilarityAnalyzer  코사인 유사도 기반 유사 문항 탐지
    ↓
AnalysisResult  →  UI 전달
    ↓
ChartCanvas  →  matplotlib 시각화 (키워드 막대 / 단원 파이)
    ↓
ReportService  →  Markdown / TXT 보고서 저장
```

## 3. 주요 기능

### 3.1 파일 불러오기

| 기능 | 설명 |
|---|---|
| 지원 형식 | PDF, CSV, XLSX, XLS, TXT |
| 다중 파일 병합 | 여러 파일을 동시에 선택하여 통합 분석 |
| 자동 컬럼 매핑 | 파일의 열 이름을 자동으로 표준 필드에 매핑 |
| 수동 매핑 | 자동 매핑 실패 시 사용자가 직접 필드 지정 |
| 파일명 메타데이터 | 파일명에서 연도·회차·시험명 자동 인식 |

```
예시: 2023_1회.pdf + 2024_1회.pdf + 2025_1회.pdf
→ 3개 파일 병합, 총 문항 수: 180
```

### 3.2 텍스트 전처리

- 특수문자 제거, 연속 공백 정규화
- **Kiwipiepy** 한국어 형태소 분석 → 명사·외래어 추출
- Kiwipiepy 미설치 시 정규식 기반 토크나이저로 자동 대체
- 조사·어미·지시문 불용어 제거, 영문 토큰 대문자 정규화
- 2자 미만 토큰, 순수 숫자, 자모 단독 문자 필터링

### 3.3 키워드 분석

- TF-IDF 알고리즘(scikit-learn)으로 핵심 키워드 추출
- 키워드별 등장 횟수(frequency) 및 문서 빈도(document_frequency) 계산
- 상위 50개 키워드 표 제공

```python
# 출력 예시
{"SQL": 145, "정규화": 121, "트랜잭션": 117, "인덱스": 98}
```

### 3.4 단원 자동 분류

chapter 컬럼이 없는 경우 **키워드 사전**으로 문항을 자동 분류한다.

| 단원 | 분류 키워드 예시 |
|---|---|
| 데이터베이스 | SQL, 정규화, 트랜잭션, ERD, 뷰, 인덱스 |
| 운영체제 | 프로세스, 스레드, 교착상태, 페이징, 커널 |
| 네트워크 | TCP, UDP, IP, 라우터, OSI, 서브넷 |
| 자료구조 | 스택, 큐, 트리, 그래프, 해시 |
| 알고리즘 | 정렬, 탐색, 다익스트라, 동적계획법 |
| 인공지능 | 머신러닝, 딥러닝, 신경망, 회귀 |
| 소프트웨어공학 | UML, 요구사항, 애자일, 폭포수, 테스트 |
| 미분류 | 해당 키워드 없음 |

출제 비중 계산식: `(단원 문항 수 / 전체 문항 수) × 100`

### 3.5 유사 문항 탐지

- TF-IDF 코사인 유사도로 반복 출제 가능성이 높은 문항 쌍 탐지
- **임계값 0.55 이상**인 문항 쌍만 결과에 표시
- 아래 경우는 자동 제외하여 의미 없는 비교 방지

| 제외 조건 | 예시 |
|---|---|
| 동일 행 비교 | 문항 A ↔ 문항 A |
| 동일 파일 내 비교 | 2025_1회.pdf의 30번 ↔ 48번 |
| 동일 연도·회차 내 비교 | 2025년 1회의 문항 간 비교 |

- 성능 보장을 위해 최대 비교 쌍 수 **3,000쌍** 제한

### 3.6 시각화

- **키워드 차트**: 상위 키워드 빈도 수평 막대 그래프
- **단원 비중 차트**: 단원별 출제 비율 파이 차트
- matplotlib FigureCanvas를 PySide6 위젯에 임베드하여 인라인 렌더링
- 한글 폰트 자동 적용 (OS별 폰트 자동 탐지)

### 3.7 보고서 생성

- **Markdown(.md)** 및 **TXT(.txt)** 형식 저장
- 보고서 포함 항목: 분석 상태 · 키워드 결과 · 단원별 비중 · 유사 문항 · 검증 이슈

## 7. 설치 및 실행

### 저장소 클론

```bash
git clone https://github.com/your-username/ExamTrend-Analyzer.git
cd ExamTrend-Analyzer
```

### 가상환경 생성 및 활성화

```bash
python -m venv .venv

# Windows (Git Bash)
source .venv/Scripts/activate

# macOS / Linux
source .venv/bin/activate
```

### 의존성 설치

```bash
pip install -r requirements.txt
```

### 한국어 형태소 분석기 설치 (선택)

```bash
pip install kiwipiepy
# 미설치 시 정규식 기반 토크나이저로 자동 대체
```

### 실행

```bash
python run.py
```

### 테스트 실행

```bash
pytest

# 커버리지 포함
pytest --cov=src/examtrend_analyzer --cov-report=term-missing
```

## 8. 사용 방법

```
Step 1  파일 불러오기
        Dashboard 화면 → [기출문제 파일 불러오기] 버튼
        PDF, CSV, Excel, TXT 단독 또는 다중 선택 가능

        ↓

Step 2  컬럼 매핑 확인
        자동 매핑 성공 → 대시보드에 "자동 매핑 완료" 표시
        자동 매핑 실패 → 수동 매핑 다이얼로그 출력

        ↓

Step 3  분석 실행
        Dashboard → [분석 실행] 버튼
        완료 시 Analysis 탭으로 자동 이동

        ↓

Step 4  결과 확인 (Analysis 탭)
        ┌───────────────────────────────────────┐
        │ 요약    │ 분석 상태 및 개요            │
        │ 키워드  │ 상위 키워드 빈도 표          │
        │ 단원별  │ 단원별 문항 수 및 출제 비중  │
        │ 유사문항│ 유사도 0.55 이상 문항 쌍     │
        │ 검증    │ 데이터 품질 이슈 목록        │
        │ 시각화  │ 키워드 차트 / 단원 파이 차트 │
        └───────────────────────────────────────┘

        ↓

Step 5  보고서 저장
        Report 탭 → [Markdown 보고서 저장] 버튼
        Markdown(.md) 또는 TXT(.txt) 선택 저장
```
