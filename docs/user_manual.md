# User Manual

## 1. 프로그램 개요

ExamTrend Analyzer는 임의의 기출문제 파일을 불러와 키워드 빈도, 자동 주제 그룹, 유사 문항 후보를 분석하는 범용 데스크톱 프로그램입니다.

특정 과목의 고정 단원 사전에 의존하지 않으므로, 정보처리기사, 한국사, 전기기사 등 다양한 시험에 적용할 수 있습니다.

---

## 2. 실행

```bash
python run.py
```

---

## 3. 파일 불러오기

대시보드에서 **기출문제 파일 불러오기** 버튼을 누릅니다.

지원 파일 형식:

- PDF (텍스트 기반)
- Excel (.xlsx, .xls)
- CSV
- TXT

여러 파일을 동시에 선택하면 자동으로 병합합니다.

---

## 4. 컬럼 매핑

파일 로드 후 시스템이 컬럼을 자동으로 탐지합니다.

자동 탐지에 성공하면 매핑 상태가 화면에 표시됩니다.  
자동 탐지에 실패하면 수동 매핑 다이얼로그가 나타납니다.

---

## 5. 분석 실행

파일을 불러온 뒤 **분석 실행** 버튼을 누릅니다.

분석이 완료되면 자동으로 Analysis 탭으로 이동합니다.

---

## 6. 분석 결과 확인

Analysis 탭에서 다음 결과를 탭으로 확인할 수 있습니다.

| 탭 | 내용 |
|---|---|
| 요약 | 분석 상태 및 파일 개요 |
| 키워드 | 상위 키워드 빈도 |
| 자동 주제 | 자동 주제별 문항 수 및 출제 비중 |
| 주제 키워드 | 자동 주제별 대표 키워드 |
| 유사 문항 | 유사도 0.55 이상 문항 쌍 |
| 검증/경고 | 데이터 품질 이슈 |
| 시각화 | 키워드 차트, 자동 주제 파이 차트 |

---

## 7. 자동 주제 분석 해석

자동 주제는 특정 과목의 단원명이 아닙니다.

입력된 기출문제 데이터에서 자주 등장하는 키워드를 기반으로 시스템이 자동 생성한 그룹입니다.

예시:

```text
주제 1: SQL, 정규화, 트랜잭션
주제 2: 통신, 프로토콜, 네트워크
주제 3: 프로세스, 스레드, 스케줄링
```

따라서 어떤 과목의 기출문제를 입력하더라도 해당 데이터에 맞는 주제 그룹이 자동으로 생성됩니다.

---

## 8. 유사 문항 분석 해석

유사 문항 탭은 서로 다른 파일 또는 서로 다른 시험 간에 내용이 유사한 문항 쌍을 표시합니다.

다음 비교는 의미 없는 결과로 간주하여 자동 제외됩니다.

- 동일 파일 내부 비교
- 동일 연도 + 동일 회차 내부 비교

---

## 9. 보고서 저장

Report 탭에서 **Markdown 보고서 저장** 버튼을 누릅니다.

지원 형식: `.md`, `.txt`

---

## 10. 주의사항

- 이미지(스캔) 기반 PDF는 텍스트 추출이 불가합니다. 텍스트 기반 PDF를 사용하세요.
- 한글이 깨지는 경우 한글 폰트(나눔고딕 등)를 설치하세요.
- `question_text` 컬럼이 없거나 매핑되지 않으면 분석이 실행되지 않습니다.
