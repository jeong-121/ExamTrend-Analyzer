# Requirements Specification

## 1. 목적

기출문제 데이터를 분석하여 출제 경향, 키워드 빈도, 단원별 비중, 난이도 변화를 사용자에게 시각적으로 제공한다.

## 2. 기능 요구사항

### FR-001 데이터 불러오기

사용자는 CSV 또는 Excel 형식의 기출문제 데이터를 불러올 수 있어야 한다.

### FR-002 텍스트 전처리

시스템은 문제 텍스트에서 불필요한 문자, 공백, 불용어를 제거할 수 있어야 한다.

### FR-003 키워드 분석

시스템은 문항 텍스트에서 주요 키워드와 빈도를 계산할 수 있어야 한다.

### FR-004 경향 분석

시스템은 연도별 출제 빈도와 단원별 비중을 분석할 수 있어야 한다.

### FR-005 난이도 분석

시스템은 연도별 또는 단원별 난이도 변화를 분석할 수 있어야 한다.

### FR-006 시각화

시스템은 분석 결과를 그래프, 워드클라우드, 히트맵 형태로 출력할 수 있어야 한다.

### FR-007 데이터 저장

시스템은 분석 대상 데이터를 SQLite 데이터베이스에 저장할 수 있어야 한다.

## 3. 비기능 요구사항

- 확장 가능한 모듈 구조를 유지한다.
- 분석 로직은 UI와 분리한다.
- 테스트 가능한 함수 단위로 구현한다.
- 대용량 데이터 처리를 고려하여 pandas 기반 처리를 사용한다.
- 오류 발생 시 사용자에게 명확한 메시지를 제공한다.
