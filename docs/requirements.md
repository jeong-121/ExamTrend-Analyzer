버전 v0.2.0 | 2026-06-01

기능 요구사항 150개 · 비기능 요구사항 100개 · 전체 250개

---

## 1. 프로젝트 개요

ExamTrend Analyzer는 임의의 기출문제 파일을 분석하여 주요 키워드, 자동 주제 그룹, 유사 문항 후보를 제공하는 범용 데스크톱 분석 프로그램이다.

특정 과목의 고정 단원 사전에 의존하지 않고, 입력된 문항 데이터에서 반복적으로 등장하는 키워드를 기반으로 자동 주제 그룹을 생성한다. 따라서 정보처리기사, 한국사, 전기기사, 국어 등 임의의 시험에 범용적으로 적용할 수 있다.

주요 특징:

- PDF, Excel, CSV, TXT 파일 지원
- 다중 파일 병합 분석
- 자동 컬럼 매핑 (한국어/영문 컬럼명 동시 지원)
- 데이터 기반 자동 주제 분석 (과목 무관)
- TF-IDF 코사인 유사도 기반 유사 문항 탐지
- PySide6 기반 데스크톱 GUI
- Markdown/TXT 보고서 자동 생성

---

## 2. 시스템 범위

본 시스템이 수행하는 기능의 범위는 다음과 같다.

파일 입력:

- PDF, Excel(.xlsx/.xls), CSV, TXT 파일 로드
- 다중 파일 동시 선택 및 병합 분석
- 파일명 기반 메타데이터(연도, 회차, 시험명) 자동 추출

분석 기능:

- 자동 컬럼 매핑 및 수동 매핑
- 키워드 빈도 분석
- N-Gram 분석 (바이그램, 트라이그램)
- TF-IDF 기반 키워드 중요도 분석
- 자동 주제 그룹 분석 및 출제 비중 산출
- 유사 문항 탐지
- 연도별 출제 경향 분석
- 난이도 분포 분석

출력:

- PySide6 GUI 화면 내 결과 표시 및 시각화
- Markdown(.md) / TXT(.txt) 보고서 생성

---

## 3. 제외 범위

다음 기능은 현재 버전(v0.2.0)의 범위에서 제외된다.

- 특정 과목 전용 고정 단원 분류 (ChapterClassifier 방식)
- N-Gram 분석 전용 화면 (파이프라인 내부에서는 실행됨)
- TF-IDF 분석 전용 화면 (파이프라인 내부에서는 실행됨)
- 난이도 분석 전용 화면 (파이프라인 내부에서는 실행됨)
- DB 저장 및 불러오기 UI (database/ 패키지는 존재하나 미활성화)
- 로그인 및 사용자 계정 관리
- 스캔 이미지 PDF OCR 처리
- 온라인 데이터 연동
- 모바일/웹 버전
