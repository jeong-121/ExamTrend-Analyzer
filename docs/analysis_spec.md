# Analysis Specification

## 1. 문서 개요

### 1.1 목적

본 문서는 ExamTrend-Analyzer의 분석 알고리즘 동작 방식을 정의한다.

시스템은 기출문제 데이터를 분석하여 다음 정보를 제공한다.

* 키워드 분석
* 단원 자동 분류
* 단원별 출제 비중 분석
* 유사 문항 분석

---

# 2. 분석 파이프라인

## 2.1 전체 흐름

```text
파일 로드
    ↓
데이터 정제
    ↓
문항 컬럼 탐지
    ↓
텍스트 추출
    ↓
키워드 분석
    ↓
단원 자동 분류
    ↓
유사 문항 분석
    ↓
결과 생성
    ↓
시각화 및 보고서 생성
```

---

# 3. 데이터 전처리

## 3.1 입력 데이터

지원 형식

* PDF
* XLSX
* XLS

* TXT


제거

적용

# 4. 키워드 분석

## 4.1 목적

기출문제에서 반복적으로 등장하는 핵심 개념을 식별한다.

---

## 4.2 입력

```text
문항 텍스트
```

예시

```text
트랜잭션의 특성으로 옳은 것은?
```

---

## 4.3 처리 과정

### 1단계

텍스트 정규화

```text
대소문자 통일
특수문자 제거
공백 정리
```

---

### 2단계

토큰 추출

예시

```text
트랜잭션
특성
```

---

### 3단계

불용어 제거

예시

```text
은
는
이
가
을
를
의
```

---

### 4단계

빈도 계산

예시

```text
SQL : 145
정규화 : 121
트랜잭션 : 117
```

---

## 4.4 출력

```python
{
    "SQL":145,
    "정규화":121,
    "트랜잭션":117
}
```

# 6. 단원별 출제 비중 분석

## 6.1 목적

단원별 출제 비율을 계산한다.

---

## 6.2 계산식

```text
(단원 문항 수 / 전체 문항 수) × 100
```

---

## 6.3 예시

```text
전체 문항 = 1000

데이터베이스 = 250

비율 = 25%
```

---

## 6.4 출력

```python
[
 {
  "chapter":"데이터베이스",
  "count":250,
  "ratio":25.0
 }
]
```

---

# 7. 유사 문항 분석

## 7.1 목적

반복 출제된 문항 후보를 탐지한다.

---

## 7.2 입력

문항 텍스트

---

## 7.3 처리 과정

### 1단계

문항 벡터화

---

### 2단계

Cosine Similarity 계산

---

### 3단계

임계값 적용

현재 기준

```text
0.55
```

이상만 채택

---

## 7.4 필터링 규칙

다음은 결과에서 제외한다.

### 동일 행

```text
문항 A ↔ 문항 A
```

---

### 동일 파일

```text
2025_1회.pdf

30번 ↔ 48번
```

---

### 동일 연도 + 동일 회차

```text
2025년 1회

30번 ↔ 48번
```

---

## 7.5 출력

```python
{
 "similarity":0.87,
 "question_1":"...",
 "question_2":"..."
}
```
