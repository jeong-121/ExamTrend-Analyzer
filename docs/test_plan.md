# Test Plan



## 1. 문서 개요



### 1.1 목적



본 문서는 ExamTrend-Analyzer의 기능 검증을 위한 테스트 계획을 정의한다.



본 테스트는 다음 목표를 가진다.



* 기능 정상 동작 검증

* 오류 처리 검증

* 데이터 무결성 검증

* UI 동작 검증

* 분석 결과 검증
