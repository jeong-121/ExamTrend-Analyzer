# Test Plan

## 1. 테스트 목적

기출문제 데이터 로딩, 전처리, 분석, 시각화 기능이 요구사항에 맞게 동작하는지 검증한다.

## 2. 테스트 범위

| 구분 | 대상 |
|---|---|
| 단위 테스트 | TextCleaner, Tokenizer, KeywordAnalyzer |
| 통합 테스트 | 파일 로딩 → 전처리 → 분석 흐름 |
| UI 테스트 | 주요 버튼 이벤트 및 화면 전환 |
| DB 테스트 | SQLite 저장, 조회, 삭제 |

## 3. 주요 테스트 케이스

### TC-001 CSV 파일 로딩

- 입력: sample_questions.csv
- 기대 결과: pandas DataFrame 반환

### TC-002 텍스트 정제

- 입력: 특수문자와 중복 공백이 포함된 문장
- 기대 결과: 정제된 문자열 반환

### TC-003 키워드 빈도 분석

- 입력: 토큰 목록
- 기대 결과: 키워드별 빈도 딕셔너리 반환

### TC-004 연도별 경향 분석

- 입력: year 컬럼이 포함된 DataFrame
- 기대 결과: 연도별 문항 수 집계 결과 반환

### TC-005 난이도 분석

- 입력: difficulty 컬럼이 포함된 DataFrame
- 기대 결과: 난이도별 빈도 또는 평균 결과 반환
