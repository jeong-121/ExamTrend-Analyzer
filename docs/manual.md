# 1. 개요

## 1.1 목적

ExamTrend Analyzer는 기출문제 데이터를 분석하여 출제 경향과 반복 출제 패턴을 파악하기 위한 데스크톱 애플리케이션이다.

PDF, Excel, CSV, TXT 파일을 불러와 키워드 분석, 자동 주제 분석, 유사 문항 탐지를 수행하고 결과를 확인할 수 있다.

특정 과목의 고정 단원 사전에 의존하지 않아 임의의 시험 과목에 범용적으로 사용할 수 있다.

# 4. 파일 불러오기

## 4.1 지원 파일 형식

```text
PDF   (텍스트 기반)
CSV
XLS
XLSX
TXT
```

---

## 4.2 단일 파일 불러오기

Dashboard 화면에서 **기출문제 파일 불러오기** 버튼을 클릭한다.

파일을 선택하면 로드 완료 상태와 문항 수가 표시된다.

예시

```text
현재 파일: 2025_1회.pdf
필드 매핑: 자동 매핑 적용 완료
문항 수: 60
```

---

# 5. 다중 파일 분석

Ctrl 또는 Shift를 사용하여 여러 파일을 선택하면 시스템이 자동 병합한다.

예시

```text
2023_1회.pdf
2024_1회.pdf
2025_1회.pdf
→ 3개 파일 병합, 총 문항 수: 180
```

---

# 6. 컬럼 매핑

## 6.1 자동 매핑

시스템이 `question_text`, `문제`, `문항`, `내용` 등의 컬럼을 자동 탐지한다.  
자동 매핑 성공 시 수동 다이얼로그 없이 바로 진행된다.

## 6.2 수동 매핑

자동 매핑에 실패하면 수동 매핑 다이얼로그가 나타난다.  
드롭다운에서 원본 컬럼과 표준 필드를 직접 연결한다.

필수 매핑: `question_text` (문항 본문)

---

# 7. 분석 실행

Dashboard에서 **분석 실행** 버튼을 클릭한다.

분석 완료 시 Analysis 탭으로 자동 이동한다.

수행 분석:

```text
키워드 분석 (빈도, 문서 빈도)
N-Gram 분석 (바이그램, 트라이그램)
TF-IDF 분석
유사 문항 분석
연도별 경향 분석
난이도 분석 (difficulty 컬럼이 있는 경우)
자동 주제 분석
```

---

# 8. 키워드 분석

빈번하게 등장하는 핵심 개념을 파악한다.

결과 예시

```text
SQL : 145
정규화 : 121
트랜잭션 : 117
```

출제 빈도가 높은 개념을 기반으로 학습 우선순위를 결정할 수 있다.

---

# 9. 자동 주제 분석

자동 주제는 특정 과목의 단원명이 아니다.  
입력된 기출문제 데이터에서 자주 등장하는 키워드를 기반으로 시스템이 자동 생성한 그룹이다.

결과 예시 (정보처리기사)

```text
주제 1: SQL, 정규화, 트랜잭션
주제 2: 통신, 프로토콜, 네트워크
주제 3: 프로세스, 스레드, 스케줄링
```

결과 예시 (한국사)

```text
주제 1: 조선, 왕권, 세종
주제 2: 근대, 개항, 조약
주제 3: 일제, 독립운동, 항일
```

이 방식은 한국사, 전기기사, 국어, 정보처리기사 등 서로 다른 과목에도 적용할 수 있다.

---

# 10. 유사 문항 분석

반복 출제 가능성이 높은 문항을 탐지한다.

제공 정보:

```text
유사도 점수
문항 A 출처 (파일명)
문항 A 본문
문항 B 출처 (파일명)
문항 B 본문
```

자동 제외 대상:

```text
동일 파일 내부 비교
동일 연도 + 동일 회차 내부 비교
```

유사 문항 목록은 읽기 전용으로 표시된다.

---

# 11. 시각화

Analysis 탭의 시각화 탭에서 확인한다.

- **키워드 차트**: 상위 키워드 빈도 막대 그래프
- **자동 주제 차트**: 자동 주제별 출제 비율 파이 차트

한글 폰트가 자동으로 탐지되어 적용된다.

# 13. 오류 해결

| 오류 | 원인 | 해결 |
|---|---|---|
| 파일 로드 실패 | 지원하지 않는 형식, 손상된 파일 | 파일 확인 후 재시도 |
| 분석 실행 불가 | 파일 미선택 | 파일 로드 후 재실행 |
| PDF 분석 실패 | 스캔 이미지 PDF (텍스트 추출 불가) | 텍스트 기반 PDF 사용 |
| 한글 깨짐 | 시스템 한글 폰트 미설치 | 나눔고딕 등 한글 폰트 설치 |
| 자동 매핑 실패 | 컬럼명 미인식 | 수동 매핑 다이얼로그에서 직접 지정 |
| PyMuPDF 오류 | PyMuPDF 미설치 | `pip install PyMuPDF` 실행 |

# 14. FAQ

## Q1. 여러 PDF를 동시에 분석할 수 있나요?

가능합니다. Ctrl 또는 Shift를 눌러 여러 파일을 선택하면 자동으로 병합합니다.

## Q2. PDF와 Excel을 함께 분석할 수 있나요?

가능합니다. 다른 형식의 파일을 동시에 선택하면 병합하여 분석합니다.

## Q3. 분석 결과를 저장할 수 있나요?

Report 탭에서 Markdown(.md) 및 TXT(.txt) 형식으로 저장할 수 있습니다.

## Q4. DB 저장 기능은 있나요?

현재 버전에서는 UI에서 제공하지 않습니다.

## Q5. 같은 시험 내부 문항도 비교하나요?

아닙니다. 동일 파일 및 동일 연도+회차 내부 비교는 자동으로 제외됩니다.

## Q6. 어떤 과목에 사용할 수 있나요?

과목 제한이 없습니다. 자동 주제 분석은 입력 데이터에서 키워드를 추출하므로 정보처리기사, 한국사, 전기기사, 국어 등 임의의 시험에 적용할 수 있습니다.
